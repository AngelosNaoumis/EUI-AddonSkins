# EUI AddonSkins 1.1.0-alpha

- Added optional Questie styling for Journey, settings and note windows.
- Added EUI accents and typography to the tracker while preserving quest colours and background opacity.
- Added scoped Questie popup-menu styling, including submenus.

Initial alpha support. Map markers, minimap pins, quest data and secure quest-item buttons remain native. Actual in-game appearance has not been verified.

Requires EllesmereUI and EllesmereUI Blizzard Skin. Questie must be installed separately. Extract `EUIAddonSkins` into `Interface/AddOns`; settings are preserved.
