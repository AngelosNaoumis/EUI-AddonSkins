# EUI AddonSkins 1.1.0-beta

- Added AtlasLootClassic Continued styling for its main window, favourites, settings, custom dropdowns, selection rows and scrolling controls.
- Preserves item-quality colours, item overlays, expansion logos, maps and models.
- Added GTFO settings styling: checkboxes, test/reset buttons, volume and damage-threshold sliders.
- Includes Questie Journey, settings, notes, tracker styling and popup menus from the alpha.
- Includes DBM options-window styling from the alpha.

DBM combat alerts, timer bars and newer Blizzard Menu popups retain their native styling. GTFO alert detection, sounds and saved settings are unchanged.

Requires EllesmereUI and EllesmereUI Blizzard Skin. Install supported addons separately. Extract `EUIAddonSkins` into `Interface/AddOns`; existing settings are preserved.

Beta release. Automated regression and packaging checks passed; actual in-game appearance has not been verified.
