# EUI AddonSkins 1.0.4

Stable release of the tested 1.0.4-beta build. No skinning behaviour changed.

- Fixed shared UI guards attempting to inspect functions or other non-UI values.
- Fixed Auctionator refresh-button discovery treating its Refresh method as a control.
- Includes the Auctionator and Dungeon Journal styling improvements.

Requires EllesmereUI and EllesmereUI Blizzard Skin. Extract `EUIAddonSkins` into `Interface/AddOns`, replacing the previous version. Settings are preserved.

Lua syntax, regression tests and packaging checks passed. The beta was reported working without Lua errors by the project owner.
