# EUI AddonSkins v1.0.0

First stable release of the optional EllesmereUI skin collection.

- Fourteen addon integrations with individual toggles under **Blizzard Skins+ > Window Skins > Third-Party Addons**.
- Follows EllesmereUI theme and accent settings, including window accents where supported.
- Styles supported windows, tabs and controls, with scoped popup-menu styling for KiwiFarm, RestedXP and TwitchEmotes.
- Event-driven discovery for loaded addons and newly created controls; coalesced refreshes and combat deferral where needed.

## Supported addons

Forever Companion, Forever Dungeon Journal, RestedXP Guides (legacy and V2), Auctionator, Spy, CrossGambling, What's Training?, ItemRack, KiwiFarm, Myslot, BugSack, Altoholic, Attune and TwitchEmotes (popup menu).

## Requirements and installation

Install EllesmereUI and enable its Blizzard Skins+ module. Install each addon you want to skin separately; none are bundled or required by the collection.

Extract the downloadable addon package into `Interface/AddOns/`, so its TOC is at `Interface/AddOns/EUIAddonSkins/EUIAddonSkins.toc`. Enable EUI AddonSkins and restart the game. Run `/reload` after disabling a skin.

## Limitations

ItemRack's secure equipment buttons and Attune's quest graph/map retain their artwork and status colors. Myslot's private import-progress dialog and shared Blizzard tooltips retain their existing styling. TwitchEmotes support covers its popup menu.

Automated syntax, mock UI and packaging checks passed for the 1.0.0 runtime. Actual WoW gameplay and rendering were not verified in the development environment.
