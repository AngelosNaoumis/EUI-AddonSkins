# EUI AddonSkins 1.2.0 — Details! and ThreatClassic2

- Added Details! meter windows, options, breakdown/report windows and pop-out menus.
- Added separate Details meter, Tiny Threat and menus/options switches. Hover the Details settings icon > **EUI AddonSkins**, or use `/euidetails`.
- Added ThreatClassic2 meter, context menu and options styling with native threat values, colours and controls preserved.
- Fixed Details header/restoration errors and raid-plugin menu switching, plus ThreatClassic2 menu reuse and checkbox font resets.

## Requirements and installation

Install EllesmereUI and enable its Blizzard Skins+ module. Install Details!, Tiny Threat and ThreatClassic2 separately as needed; each integration is optional.

Extract the release ZIP's `EUIAddonSkins` folder into `Interface/AddOns/`, replacing the previous addon folder. Enable EUI AddonSkins and restart the game.

## Settings

Individual skins can be toggled in **Blizzard Skins+ > Window Skins > Third-Party Addons**. Details menus/options styling is enabled by default; meter matching and Tiny Threat styling are opt-in for new installations. Meter styling restores the appearance settings captured when enabled. Reload after changing menu styling or disabling an integration.

Details retains window positions, sizes, data and interactions. EUI meter appearance settings are reused when available; exact renderer parity is not guaranteed. ThreatClassic2 retains its native row geometry and warning/class colours.
