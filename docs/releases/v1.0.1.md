# EUI AddonSkins v1.0.1

- Fixed the native-style flash when opening supported popup menus and submenus.
- Added scoped styling for Altoholic's AddonFactory menus, navigation, legacy scrollbars, toolbar icons and contained square header portrait.
- Styled Attune quest cards, icons, tree selection, expand/collapse controls, zoom slider and contained square header portrait. Quest-state colours and graph interactions remain intact.
- Completed Forever Dungeon Journal header controls, language picker, dungeon-card borders, scrollbar and resize-grip styling. Dungeon artwork and status indicators remain intact.
- Window accents continue to respect EUI's colour and visibility settings.

Requires EllesmereUI with Blizzard Skins+ enabled. Install supported addons separately. Replace the EUIAddonSkins folder and restart the game.

Altoholic's bottom tabs retain their native external anchors to avoid overlapping content. Automated syntax, mock UI and packaging checks pass; actual in-game rendering has not been verified in this environment.
