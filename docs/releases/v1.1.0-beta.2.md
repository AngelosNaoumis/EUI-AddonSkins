# EUI AddonSkins 1.1.0-beta.2

- Added ThreatClassic2 monitor typography, EUI accents and settings controls. Threat values, class colours, warnings, bar textures and update logic remain native.
- Added Gargul styling for owned windows, dialogs, settings, dropdown menus, sliders, input boxes, icons and resize controls.
- Supports dynamically created Gargul interfaces and preserves loot actions, countdown colours and custom font-size methods.
- Includes Questie, DBM, AtlasLootClassic Continued, GTFO and all previous skins.

Requires EllesmereUI and EllesmereUI Blizzard Skin. Install supported addons separately. Extract `EUIAddonSkins` into `Interface/AddOns`; existing settings are preserved.

Beta release. Automated regression and packaging checks passed; actual in-game appearance has not been verified. ThreatClassic2’s modern Blizzard context menu and DBM’s combat alerts, timer bars and newer Blizzard Menu popups retain native styling.
