# EUI AddonSkins 1.1.0-alpha.2

- Added optional Deadly Boss Mods options-window styling with EUI accents, tabs, category toggles, sliders, buttons and dropdown controls.
- Supports DBM-GUI loading on demand and dynamically created options panels.
- Preserves DBM colour swatches, model previews, combat alerts and timer bars.
- Includes the Questie skin from 1.1.0-alpha: Journey, settings, notes, tracker styling and popup menus.

Initial alpha support. Newer DBM Blizzard Menu popups retain their existing styling. Actual in-game appearance has not been verified.

Requires EllesmereUI and EllesmereUI Blizzard Skin. Install DBM and Questie separately as needed. Extract `EUIAddonSkins` into `Interface/AddOns`; settings are preserved.
