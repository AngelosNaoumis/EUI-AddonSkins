# EUI AddonSkins 1.0.4-beta

- Fixed `attempt to index local f (a function value)` in the shared UI guard.
- Auctionator refresh-button discovery now ignores its Refresh method.
- Added regression coverage for functions, numeric IDs and other non-UI values.

Beta release. Includes the existing Auctionator and Dungeon Journal styling fixes. Settings are preserved.

Requires EllesmereUI and EllesmereUI Blizzard Skin. Extract `EUIAddonSkins` into `Interface/AddOns`, replacing the previous version.

All automated regression suites, Lua syntax and packaging checks passed. Actual in-game behaviour was not verified.
